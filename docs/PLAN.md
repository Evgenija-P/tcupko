# План реалізації — tcupko, реліз 1

Мета: публічний каталог + кошик + оформлення замовлення без онлайн-оплати, $0 на хостинг.
Поза релізом 1: адмінка, особистий кабінет, онлайн-оплата.

## Стек і рішення

| Що | Рішення | Чому / ліміти free |
|---|---|---|
| Фреймворк | Next.js (App Router) + TS + Tailwind v4, npm | — |
| Хостинг | Cloudflare Workers + `@opennextjs/cloudflare` | 100k запитів/добу, SSL, CDN, DDoS — без налаштувань. Vercel Hobby заборонює комерційне використання |
| Деплой | Workers Builds з GitHub: `main` → прод, `dev` → preview URL | безкоштовно, без CI-конфігів |
| БД | Cloudflare D1 (SQLite) + Drizzle ORM | 5 GB, міграції в репо |
| Фото | Cloudflare R2 | 10 GB, без плати за трафік |
| Листи | Resend + React Email | 3000/міс, 100/добу; потрібен свій домен |
| Антиспам | Cloudflare Turnstile + honeypot | безкоштовно |
| Валідація | zod (спільна схема клієнт/сервер) | — |
| Аналітика | Cloudflare Web Analytics | без cookie-банера |

Ризик: ліміт розміру Worker на free (3 MiB стиснено). Перевіряємо з першого деплою; тримаємо
залежності мінімальними.

## Модель даних (D1)

- `categories` (id, slug, name, sort)
- `products` (id, slug, name, description, price_uah — цілі копійки, stock, is_active, category_id)
- `product_images` (product_id, r2_key, alt, sort)
- `orders` (id, number, created_at, name, phone, email, carrier `np|ukrposhta`,
  delivery JSON, payment `iban|cod`, subtotal, discount, total, comment, status,
  ship_date, customer_email_sent_at, owner_notified_at)
- `order_items` (order_id, product_id, name, price, qty) — знімок ціни на момент замовлення

Товари до появи адмінки: JSON/CSV у репо → `npm run db:seed` (а не сирий SQL руками).

## Логіка замовлення

1. Кошик — у `localStorage`, показує суму, знижку і «до знижки залишилось N грн / N шт»
   (та сама `pricing.ts`). Кількість не більша за залишок.
2. Форма: ПІБ, телефон (+380), email, перевізник, доставка, оплата, коментар.
   - НП: місто + відділення або поштомат (без кур'єра) через API НП; оплата IBAN або
     накладений. Попередження про комісію НП за накладений платіж.
   - Укрпошта: індекс + місто + адреса; оплата лише IBAN.
   - Доставка за тарифами перевізника, безкоштовної немає.
3. Server action: zod → Turnstile → перерахунок цін із БД → знижка → правила оплати →
   списання залишку (умовний UPDATE `stock >= qty`, без продажу «в мінус») → запис
   замовлення → листи + Telegram. Збій листа не скасовує замовлення.
4. **Знижка 10 % на все замовлення**, якщо: будь-якого товару ≥ 15 шт **або** сума кошика
   ≥ 3500 грн (до знижки). Знижки не сумуються — завжди 10 %.
5. **Відправка:** середа й субота, відсічка 11:00 (Europe/Kyiv). Замовлення до 11:00 у день
   відправки — їде того ж дня, пізніше — наступного дня відправки. Для IBAN — рахуємо від
   моменту оплати.
6. Листи: покупцю IBAN — реквізити, сума, призначення «Замовлення №…», QR НБУ, термін
   оплати 48 год; покупцю накладений — коротке підтвердження без реквізитів.
   Власниці — Telegram-бот (+ лист).
7. Сторінка «Дякуємо»: номер, сума, реквізити з кнопками «копіювати», QR НБУ, дата відправки.
8. **Залишки:** закупівель немає, розпродаж. Товар із `stock = 0` зникає з каталогу й
   sitemap, сторінка товару → 404. Неоплачене за 48 год замовлення скасовується, залишок
   повертається (Cron Trigger Cloudflare, безкоштовно).
9. Реквізити (отримувач, IBAN, ЄДРПОУ/РНОКПП) — лише в секретах Cloudflare.

## Наступний реліз
Адмінка (товари, замовлення, статуси «оплачено/відправлено», ТТН), особистий кабінет.

## Відкриті питання
- Як позначати «оплачено» до появи адмінки (від цього залежить автоскасування за 48 год):
  пропозиція — кнопки «Оплачено / Скасувати» в Telegram-повідомленні про замовлення.
- Домен — ще не куплений (потрібен до етапу 7: Resend, SEO).
- Доступ до Figma через MCP.
