# План реалізації — tcupko («Цупко»), реліз 1

Мета: публічний каталог + кошик + оформлення замовлення без онлайн-оплати, $0 на хостинг.
Поза релізом 1: адмінка, особистий кабінет, онлайн-оплата.

## Стек і рішення

| Що                  | Рішення                                                     | Чому / ліміти free                                                                |
| ------------------- | ----------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Фреймворк           | Next.js (App Router) + TS + Tailwind v4, npm                | —                                                                                 |
| Хостинг             | Cloudflare Workers + `@opennextjs/cloudflare`               | 100k запитів/добу, SSL, CDN, DDoS. Vercel Hobby заборонює комерційне використання |
| Деплой              | Workers Builds з GitHub: `main` → прод, `dev` → preview URL | без CI-конфігів                                                                   |
| БД                  | Cloudflare D1 (SQLite) + Drizzle ORM                        | 5 GB, міграції в репо                                                             |
| Фото                | Cloudflare R2                                               | 10 GB, без плати за трафік                                                        |
| Листи покупцям      | Resend + React Email                                        | 3000/міс, 100/добу; потрібен домен                                                |
| Сповіщення власниці | Telegram-бот (замовлення, «в один клік», форми)             | безкоштовно; на пошту власниці нічого не шлемо                                    |
| Автоскасування      | Cloudflare Cron Trigger                                     | безкоштовно                                                                       |
| Антиспам            | Cloudflare Turnstile + honeypot                             | безкоштовно                                                                       |
| Валідація           | zod (спільна схема клієнт/сервер)                           | —                                                                                 |
| Аналітика           | Cloudflare Web Analytics                                    | без cookie → без cookie-банера                                                    |

Ризик: ліміт розміру Worker на free (3 MiB стиснено) — перевіряємо з першого деплою.

## Макет (Figma `j2QGPnHMNhNLILfHKyDile`)

Десктоп 1440 + мобільна 390. «05 Акаунт» і «07 Адмінка» — не в релізі 1.

**Робимо:** головна (слайдер, категорії, каруселі Акції/Новинки/Бестселери, переваги,
банер «Оптовим покупцям», «Про магазин»), мегаменю, пошук із підказками, мобільний
каталог на 2 рівні; категорія, підкатегорія з фільтрами, сортуванням і пагінацією, пошук,
порожні стани; товар (галерея + повноекранна, максимум = залишок, «Купити в один клік»,
таблиця розмірів, «Додано до кошика»); кошик (повний/порожній), контакти гостя, помилка
телефону, НП / Укрпошта / Meest / Самовивіз, «Зміна залишку», «Замовлення оформлено»;
інфосторінки (Про магазин, Доставка та оплата, Обмін і повернення, Оферта,
Конфіденційність, Контакти + форма, Оптовим покупцям + форма, 404).

**Не робимо:** оплата карткою, редирект/успіх/помилка оплати, таймер резерву і «Час
резерву вичерпано», «Контакти покупця» (кабінет), «Повідомити про надходження», «Немає в
наявності», cookie-банер і налаштування cookie.

**Правка тексту:** банер героя «Гуртові ціни від 10 шт» → під правило знижки
(«−10 % від 15 шт одного товару або від 3500 ₴»).

## Каталог, розміри, фільтри

- **Категорії — дерево на 2 рівні** (мегаменю): Захист очей та обличчя, Захист органів
  дихання, Захист рук, Спецодяг, Абразиви, Зварювання, Захист голови та слуху → підкатегорії
  (Відрізні круги, Шліфувальні круги, Електроди, Зварювальний дріт, Ізолента, Беруші,
  Маркери, Рулетки, Щітки, Фартухи, Налокітники…). Товар лежить в одній підкатегорії.
- **Призначення — теги** (багато-до-багатьох): «захист очей», «захист рук», «зварювання»,
  «обробка металу», «електрика», «розмітка й вимірювання»… Вони поєднують різнокаліберні
  товари: краги — і «захист рук», і «зварювання». Фільтр «Призначення» + сторінки
  тегів не робимо, лише фільтр.
- **Характеристики — гнучкі пари `ключ → значення`** (матеріал, бренд, діаметр круга,
  товщина, діаметр електрода/дроту, довжина рулетки…). Фільтри будуються **автоматично з
  товарів поточної категорії**: група показується, лише якщо в ній ≥ 2 значення. Тоді в
  «Рукавицях» буде матеріал і розмір, а в «Кругах» — діаметр і товщина, без ручних налаштувань.
- **Ціна від–до** — завжди; **сортування:** популярні (ручний порядок), ціна ↑↓, новинки.
- **Розміри — варіанти товару.** Товар без розміру має один варіант. Товар із розмірами
  (M, L, XL…) має кілька варіантів, у кожного свій залишок; ціна спільна (якщо
  відрізняється — окреме поле у варіанті). У кошику позиція = варіант. Фільтр «Розмір»
  зʼявляється сам, де є розміри.
- **Таблиця розмірів** — одна на категорію (спецодяг, рукавички), показується лише на
  товарах із розмірами. Немає таблиці — кнопки немає.
- **Акції / Новинки / Бестселери** — ручні прапорці; акція = `old_price` (перекреслена).
- **Пошук** — по назві й коду товару (SQLite `LIKE` / FTS5), підказки: 5 товарів + 3
  категорії.

## Модель даних (D1)

- `categories` (id, parent_id, slug, name, description, tip, size_chart, sort)
- `products` (id, sku/код, slug, name, description, price, old_price, category_id,
  is_new, is_bestseller, sort, is_active)
- `product_variants` (id, product_id, size NULL, price NULL, stock)
- `product_attributes` (product_id, key, value) · `tags`, `product_tags`
- `product_images` (product_id, r2_key, alt, sort)
- `orders` (id, number, created_at, name, phone, email, carrier
  `np|ukrposhta|meest|pickup`, delivery JSON, payment `iban|cod|cash`, subtotal, discount,
  total, comment, status `new|paid|shipped|cancelled`, ship_date, pay_until,
  customer_email_sent_at, owner_notified_at)
- `order_items` (order_id, variant_id, name, size, price, qty) — знімок на момент замовлення
- `leads` (id, type `one_click|contact|wholesale`, name, phone, email, payload, created_at)

Гроші — цілі копійки. Товар із сумарним залишком 0 зникає з каталогу й sitemap, сторінка → 404.
Товари до адмінки: JSON/CSV у репо → `npm run db:seed`, фото → R2 скриптом.

## Логіка замовлення

1. Кошик у `localStorage`; сума, знижка, «до знижки залишилось N ₴»; кількість ≤ залишку.
2. Форма (гість): ПІБ, телефон (+380, маска), email, перевізник, оплата, коментар.

   | Перевізник | Дані доставки                                     | Оплата                                           |
   | ---------- | ------------------------------------------------- | ------------------------------------------------ |
   | Нова пошта | місто + відділення/поштомат (API НП), без кур'єра | IBAN або накладений (+ попередження про комісію) |
   | Укрпошта   | індекс, місто, адреса                             | лише IBAN                                        |
   | Meest      | місто + відділення (текстом)                      | лише IBAN                                        |
   | Самовивіз  | — («час і місце узгодимо телефоном»)              | IBAN-передоплата або готівка на місці            |

   Доставка — за тарифами перевізника, безкоштовної немає.

3. Server action: zod → Turnstile → ціни з БД → знижка → правила перевізник↔оплата →
   атомарне списання залишку (`stock >= qty`, інакше екран «Зміна залишку») → замовлення
   → лист покупцю + Telegram. Збій листа/Telegram не скасовує замовлення.
4. **Знижка 10 % на все замовлення**, якщо будь-якого товару ≥ 15 шт **або** сума ≥ 3500 ₴
   (до знижки). Не сумується.
5. **Відправка:** середа й субота, відсічка 11:00 Europe/Kyiv; для IBAN — від оплати.
   Самовивіз — без дати, за домовленістю.
6. **Лист покупцю:** IBAN — реквізити, сума, призначення «Замовлення №…», QR НБУ, оплатити
   до (48 год); накладений / готівка — коротке підтвердження.
7. **«Замовлення оформлено»:** номер, сума, реквізити з «копіювати», QR НБУ, дата відправки.
8. **Telegram власниці:** повідомлення про замовлення з кнопками «Оплачено» / «Скасувати»
   (webhook із секретним токеном). Скасування повертає залишок.
9. **Cron** щогодини: IBAN-замовлення без оплати > 48 год → `cancelled`, залишок назад,
   повідомлення в Telegram.
10. **«Купити в один клік»:** телефон (+ товар, варіант, кількість) → `leads` + Telegram;
    залишок не списується, замовлення оформлює власниця після дзвінка.
11. Форми «Контакти» і «Оптовим покупцям» → `leads` + Telegram. Пошту не використовуємо.
12. Реквізити (отримувач, IBAN, код), ключі Resend/НП/Telegram — лише секрети Cloudflare.

## Наступний реліз

Адмінка (товари, замовлення, статуси, ТТН), особистий кабінет, можлива онлайн-оплата.

## Відкриті питання

- Домен (потрібен до етапу 8: Resend, SEO).
- Тексти «Про магазин», переваги, оферта, повернення — від власниці.
- Іконки категорій: у Feather немає відповідних — надати або намалювати.
